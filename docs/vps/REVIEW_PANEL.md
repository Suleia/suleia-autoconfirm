# Review panel

The local prototype provides:

- safety-state banner;
- operational summary;
- source freshness;
- pending AI and human review counts;
- a masked fictitious order example;
- proposed action, confidence and evidence;
- explicit zero-actions indicator.

## Future read-only views

- orders requiring review;
- order timeline;
- active timers;
- source freshness;
- decision comparison;
- QA findings;
- audit trail.

The panel has no execution buttons in staging. A future reviewer action would require authenticated, audited, separately authorized APIs.
