# Cost report

## Expected monthly infrastructure

Preliminary figures before VAT, excluding domain and independent off-site storage:

- OVHcloud VPS-2: from EUR 7.21/month.
- Hetzner CAX21: EUR 10.49/month plus EUR 0.50/month for IPv4 if required.
- Scaleway DEV1-M: about EUR 14.74/month plus storage and IPv4.

An independent encrypted backup target is still required even when the provider includes snapshots.

## Software

- Ubuntu LTS: no license cost.
- Docker Engine: no license cost for this deployment.
- Caddy: no license cost.
- PostgreSQL: no license cost.
- Node.js: no license cost.
- Uptime Kuma: no license cost.
- OpenAI API: intentionally EUR 0.

## Hidden operational costs

- VPS administration time.
- Security patching.
- Backup restore drills.
- Monitoring response.
- Migration rehearsal.
- Incident response.

The lowest server price is not automatically the lowest total cost. The preliminary OVHcloud recommendation values included daily backup and a simple x86 environment.
