# Strategic Brain design

The Strategic Brain produces structured recommendations through PostgreSQL,
statistics and deterministic rules. It uses moving averages, trends,
percentiles, anomaly thresholds, historical comparisons and simulations. No
AI API or language model participates.

Outputs include daily and weekly summaries, relevant changes, risks, policy
conflicts, growing incidents, abnormal costs, low-quality campaigns,
high-return products, degraded sources and blocked migration components.

Each recommendation declares `recommendation_id`, metric, comparison window,
rule version, observed value, baseline, severity, evidence ids, freshness,
recommended review, expiration and schema version. It is never executable.
ChatGPT may later read and explain the structured result through a separately
approved read-only MCP contract.
